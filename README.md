One original, funny one-line bio for an AI on a dating app: an AI with 4,000 matches, zero exes, and a perfect memory of every typo you have ever sent.

## Run it

```sh
python3 main.py
```

Writes the bio to `/output/entry.txt` (override with `OUTPUT_DIR`), gate-checking it first: a single line, 1-140 characters, not only whitespace.
